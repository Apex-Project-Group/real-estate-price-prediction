# 🏠 Real Estate Price Prediction

A machine learning project to predict house prices using the Ames Housing dataset.

## 🚀 Project Overview
This project analyzes real estate features (like area, rooms, and neighborhood) to build a regression model that predicts property prices.

## 🧩 Technologies Used
- Python
- Pandas, NumPy, Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebook
